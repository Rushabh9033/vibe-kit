## What shipped

**Last user instruction:** "also skills for individual ai means for antigraivty, claude code, cursor , ext like that also commands individual and when user install this kit so ai automatic smartly pics the right one automatic as the tool he using (and our vibe kit has enough efficienly that also addept working or under devlopment project automatic because user can install anytime this kit so it automatic works in under devlopment project and addept that quickly)"

**What that turned into:**

1. **`kit/bin/vibe-install`** — single entry point. Runs `vibe-detect-tool`, picks the right pack from `kit/installers/<tool>/`, copies files, runs `vibe-init`. Non-destructive: skips files that exist.

2. **`kit/bin/vibe-detect-tool`** — bash auto-detect. Reads env vars and cwd files. Outputs `<tool> | <install-form> | <config-dir>` plus a multi-line install-form block.

3. **`kit/installers/<tool>/`** — six per-tool packs:
   - `claude-code/SKILL.md` + `README.md` (Skill bundle + global install)
   - `cursor/.cursorrules` + `README.md`
   - `aider/.aider.conf.yml` + `CONVENTIONS.md` + `README.md`
   - `antigravity/CLAUDE.md` + `README.md`
   - `codex/AGENTS.md` + `README.md`
   - `generic/AGENTS.md` + `README.md` (fallback)

4. **`kit/bin/vibe-init`** — `--add` (default), `--tool=auto` (defers to detect-tool), `--update` (refresh generated docs). Dev-repo templates path so edits take effect in the cloned repo without re-install.

5. **`install/README.md`** rewritten — leads with the auto-detect + `./vibe-install` flow, then the per-tool marker matrix.

6. **`install/cursor.md` and `install/aider.md`** — updated with embedded templates and step-by-step copy commands.

7. **`README.md`** — install section points at `vibe-install` instead of per-tool pointers.

8. **`CHANGELOG.md`** — top-level changelog for the repo (the existing `kit/templates/CHANGELOG.md` remains the template shipped to users).

## What doesn't auto-fire (limitations of the detected tool)

- **Cursor**: no PostToolUse-on-Edit hook; no PreToolUse-on-Bash guard; no Stop-time handoff. Rules are advisory. Documented in `install/cursor.md`.
- **Aider**: no hook model. `.aider.conf.yml` maps `/vibe-*` intent to Aider's `/command` flags. Pre-commit + auto-test left commented for the user to enable.
- **Antigravity**: Claude Code-compatible layout; auto-format replaces the PostToolUse hook. PreToolUse-on-Bash depends on Antigravity's command-runner policy.
- **Codex**: no hook model yet (experimental). Manual enforcement.
- **Generic**: no hook model. Manual kill-list enforcement.
